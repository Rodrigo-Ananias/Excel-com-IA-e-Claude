O objetivo dessa aula é saber utilizar as fórmulas mais utilizadas em relatórios no quesito de data e hora.

Dentro dessa aula vamos aprender fórmulas como mês ano e dia, a formatação dessas datas e fórmulas não listadas. Vamos aprender como as datas se comportam no Excel e qual são os seus caminhos.

- Ano, Mês e Dia

ANO retorna o ano de uma data específica.
MES retorna o mês de uma data específica.
DIA retorna o dia de uma data específica.

São fórmulas básicas de auxiliam na produção de fórmulas mais complexas.

- Dia da Semana

DIA.DA.SEMANA retorna o dia da semana de uma data específica por um critério específico.

- Datadif

São fórmulas não listadas que ajudam na produção de relatórios. Por exemplo, a fórmula datadif que aponta duas datas para ele e ver a diferença de unidades entre duas datas. Pode ser a diferença entre dias, entre meses, entre anos e etc. 
O primeiro parâmetro é a data inicial, seguido pela data final e, por fim, o parâmetro entre aspas duplas. 

=DATADIF(data inicial;data_final;"parâmetro")

Os parâmetros podem ser

"D": Número de dias entre as duas datas.
"M": Número de meses completos entre as duas datas.
"Y": Número de anos completos entre as duas datas.
"MD": Diferença em dias, ignorando meses e anos.
"YM": Diferença em meses, ignorando anos.
"YD": Diferença em dias, ignorando anos.

A fórmula DATADIF calcula a diferença entre duas datas, podendo retornar o resultado em anos, meses ou dias, conforme o parâmetro escolhido.

- Possíveis Erros

Para obter a data atual é só clicar CTRL + ;

Toda data para o EXCEL é um número. A menor data do Excel é 01/01/1900. Identificar problemas é essencial.

Uma identificação dos erros é --, X e 01/01/1900. 

- Combinação de fórmulas

=ÉNÚM verifica se a célula é um número e retorna valor verdadeiro ou falso.
=E verifica uma combinação lógica. Se ambos os argumentos forem verdadeiros, retorna verdadeiro. É E de Exigente.
=SEERRO volta um valor específico se encontrar erro.

Uma outra forma de embelezar uma fórmula é por meio do site Excel Formula Beautifier. 

- FIMMÊS

É uma fórmula que inseri um deadline (data limite) em meses. Ela serve para descobrir qual que é o último dia daquele mês.

A fórmula FIMMÊS retorna a última data de um mês, dado um número de meses antes ou depois de uma data inicial.

- SEERRO

É uma fórmula muito útil para realizar a limpeza de datas. Caso apareça um erro, você pode configurar para retornar um valor específico como "falso", "" e etc.

- Observações

O Excel converte datas em números, onde o número representa o número de dias desde 1º de janeiro de 1900.

Fórmulas de data no Excel são usadas para manipular, calcular e extrair informações relacionadas a datas, como ANO, MÊS, DIA, DATA, FIMMÊS, entre outras.
